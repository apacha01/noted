# Noted

A mobile-first music note trainer built with Astro, Preact, Tailwind CSS, and VexFlow.

## Commands

```sh
npm run dev
npm run build
npm test
```

Progress and preferences are stored locally in the browser. The interface supports English and Spanish, letter and fixed-do note names, sharp/flat/mixed spellings, light/dark/system themes, four practice modes, treble and bass clefs, custom note sets, and continuous practice sessions.
